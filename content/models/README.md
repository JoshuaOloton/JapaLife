# models/

`catalog.json` lists every 3D model the client can draw, measured from its real geometry: footprint, height, triangles and file size. It is **generated by `pnpm assets`**: change the pipeline (`apps/client/scripts/assets/`), not this file.

A building in `cities/<city>.json` names a model with `model`. The footprint in the city file stays the collision truth, and the server refuses to start if a model does not fill it (at most 0.3 m bigger, at least 85% of it on each axis).
